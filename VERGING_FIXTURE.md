# Basic Memory onboarding fixture

This staging-only synthetic customer repository is a clean fork of Basic
Memory. Its staging branch contains a neutral health/build scaffold so Railway
can prove source-linked deployment before the customer integration test.

There is intentionally no Verging adapter, adapter route, authentication
scheme, or answer to the final onboarding prompt in this repository. The
customer coding agent must implement the integration from the generated
onboarding instructions.
